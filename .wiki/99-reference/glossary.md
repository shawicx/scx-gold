# 术语表

本项目涉及的 A 股交易、技术分析、工程术语。

## A 股交易术语

| 术语 | 说明 |
| ---- | ---- |
| 涨停 | A 股股价当日涨幅触及上限（主板 10%、创业板/科创板 20%、ST 5%），封死不再上涨 |
| 封涨停 | 涨停价位上有大量买单封住，卖单无法砸开（线索标签 `封涨停` 判定：涨幅 ≥9.95% 且现价 ≥ 最高价 × 0.999） |
| 接近涨停 | 涨幅 9.5%–9.95%，即将触及涨停（线索标签） |
| 炸板 | 涨停后又被砸开（冲高回落），现价 < 最高价 × 0.99 判定为「炸板风险」 |
| 主力净流入 | 主力资金（大单）买入额减卖出额，正值表示主力净买入（东方财富 f62） |
| 主力净流入占比 | 主力净流入占成交额比例（东方财富 f184） |
| 换手率 | 当日成交量占流通股本比例（%），高换手 = 放量，低换手 = 缩量 |
| ST | 特别处理股票（财务异常等），名称带 `ST` 前缀，默认筛选排除 |
| 主板 | 上海主板（600/601/603）+ 深圳主板（000/001/002），不含创业板/科创板/北交所 |
| 全部 A 股 | 主板 + 创业板（300/301）+ 科创板（688）+ 北交所（430/83/87） |
| 交易时段 | 北京时间 早盘 09:15–11:30、午盘 13:00–15:30（周末非交易） |

## 技术分析术语（ETF 支撑位分析）

| 术语 | 说明 |
| ---- | ---- |
| 支撑位 | 价格下跌时预期遇支撑的价位（买盘集中），本项目计算 support_1/support_2 |
| 压力位 | 价格上涨时预期遇阻的价位（卖盘集中），本项目计算 resistance_1 |
| MA20 / MA60 | 20 日 / 60 日移动平均线，常用支撑/压力位来源 |
| BOLL | 布林带（上轨/中轨/下轨），下轨常作支撑 |
| 强度 | 支撑/压力位强度标签：强 / 中 / 弱（命中来源越多越强） |

## 黄金品种术语

| 术语 | 说明 |
| ---- | ---- |
| 沪金主连 AU0 | 上期所（SHFE）黄金期货连续合约（主力合约拼接） |

## 工程术语

| 术语 | 说明 |
| ---- | ---- |
| JSONP | JSON with Padding，通过 `<script>` 标签跨域获取数据的旧技术，东方财富接口使用 |
| SPA | Single Page Application，单页应用，本项目用 BrowserRouter history 路由 |
| 授权码认证 | 本项目的门禁机制：后端生成 16 位随机码发邮箱，前端校验后存 localStorage |
| ApiError | 本项目统一的业务/HTTP 错误类型（`src/service/request.ts`），含 status 与 code |
| 统一响应 | 后端所有业务接口返回 `{ code, message, data }`，code===0 成功 |
| ACR | 阿里云容器镜像服务（Alibaba Cloud Container Registry） |
| ECS | 阿里云弹性计算服务（云服务器），部署目标 |
| service 层 | `src/service/` 下由 `@scxfe/api-tool` 生成的后端 API 调用代码 |
